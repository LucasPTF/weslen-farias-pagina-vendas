# Selo Verde em 72h

Página de vendas da aula Selo Verde em 72h, de Weslen Farias.

## Tecnologias

React, Vite, CSS responsivo e Vercel.

## Rotas

- `/a1`
- `/a2`
- `/a3`
- `/obrigado`

As três rotas de venda compartilham todos os componentes e conteúdos. Somente a comunicação da seção inicial muda entre elas.

## Execução local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Informações pendentes

O projeto está preparado para receber o link de checkout, a data da próxima turma, o canal oficial de suporte e os depoimentos identificados quando esses materiais forem fornecidos.
